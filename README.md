# HGhub

**基于 Rust 与 Tauri 2 的跨平台界面与交互实践项目。**

HGhub 起源于个人对 Tauri 2 和移动端开发的学习与尝试。感谢大家的关注与贡献；项目由个人利用业余时间维护，关注度的增长不会改变维护范围，也不代表服务或支持承诺。

## 免费加密 DNS 自动恢复（无须填写代理）

当本机 DNS 对 HTTPS 网站解析失败或超时时，HGhub 会自动尝试 Cloudflare 和 Google 的公开 DNS-over-HTTPS（DoH）服务。请求始终验证 HTTPS 证书，并拒绝私有地址、FakeIP 和保留 IP；不会自动关闭严格安全模式，也不会修改系统 DNS。加密 DNS 只收到要查询的**主机名**，不包含账号密码、查询路径、登录令牌等数据。无需注册或手动输入代理端口。

**能力边界：** 只能缓解 DNS 本身的故障与部分 DNS 污染。若网站的 IP/SNI/TLS 流量被拦截，或视频接口、CDN、账号授权有问题，DoH 不会自动建立外部隧道或绕过网站权限。联网诊断中增加 `secure_dns` 字段说明这一功能。

## 网络自动恢复（无需填写代理）

默认开启：当 HGhub 使用 **内置固定线路** 时，匿名 GET 读取或无凭据的只读播放地址查询遇到 DNS、连接超时或 HTTP 502/503/504 等临时网络故障，会自动尝试另一条内置固定线路（`huangguoai.com` / `huangguoai.ai`）。它不会更改你手动选择的线路、保存的账号或观看记录，也不会转发登录、带 Token、评论、收藏或其他写入数据的请求。macOS 的「跟随系统」模式还会自动读取系统中已启用的 HTTP/HTTPS 代理（不需要手工填端口）；不会自动执行 PAC/WPAD 代理脚本，也不会寻找或连接未知本地代理端口。

**限制：** 网站首页返回 HTTP 200 不能保证内容接口或视频分片正常，所以「设置 → 网络 → 检测连接」现在另外测试真实的匿名视频列表 API。若两条固定线路都不可用，或视频文件位于其他被限制的服务上，仍需要可信的系统代理/VPN 或合法备用来源；应用不会自动提供代理服务器，也不会绕过访问权限或付费限制。

## 网络受限时的代理设置

若当前 Wi-Fi、运营商或 DNS 无法访问内容来源，可在 **设置 → 网络 → 网络访问方式** 中选择：

1. **跟随系统**：使用操作系统或环境变量配置的代理。不同系统与代理软件的识别方式可能不同。
2. **直接连接**：明确忽略系统代理，用于排除错误代理的影响。
3. **手动代理**：填入你自己信任的 HTTP(S) 代理，例如 `http://127.0.0.1:7890`；先在电脑上运行提供该端口的代理软件，然后保存并点击「检测连接」。Clash 等程序请填 **HTTP/Mixed 端口**，不是仅限 SOCKS 的端口。

手动代理会用于应用的 Rust 网络请求，包括内容接口、图片及播放分片；HTTP CONNECT 请求会把域名交给代理建立连接，在某些本地 DNS 受限的环境下更容易访问。**本应用不提供代理服务器或代理账号，不保证外部来源始终可用。** 只使用可信代理；代理可能知道你访问的域名，代理地址禁止包含用户名和密码。

配置仅保存在本机 `proxy.json`，切换代理不更改收藏、观看记录或登录会话。严格安全模式仍限制直接访问的私有 IP 和应用内部域名；代理代为解析域名时，本机无法验证它最终对应的 IP，所以应只启用你信任的代理。网络诊断中的本地 DNS 失败，不代表代理连接也失败。

## macOS 安装与故障排查（独立发行版）

**[GitHub 仓库网页](https://github.com/Dreaminmaster/HGhub) · [macOS 安装包](https://github.com/Dreaminmaster/HGhub/releases)**

- `https://github.com/Dreaminmaster/HGhub.git` 是 **Git 克隆地址**。浏览仓库时请使用上面的网页地址，不需要同步上游。
- Apple Silicon（包括 M5）请选择 `arm64.dmg`，Intel 请选择 `x64.dmg`。安装时将 HGhub 拖入「应用程序」。不要先删除旧的应用数据。
- **双击后被 macOS 阻止**：目前安装包采用临时签名而非 Apple Developer ID 签名及公证。确认下载来源后尝试打开一次，再前往「系统设置 → 隐私与安全性 → 仍要打开」；这一操作仅针对你确认信任的版本，不要全局关闭 Gatekeeper。若系统提示文件真实损坏或应用仍闪退，应收集日志而不是盲目清除隔离属性。
- **可以启动但首页空白／无法播放**：这与 macOS 启动拦截不同。使用应用内「设置 → 网络诊断」查看 DNS、代理和服务器响应；必要时检查「设置 → 线路」。该旧版依赖第三方服务接口，第三方接口变动不能靠同步 GitHub 仓库恢复。
- **调试日志**：可在 Finder 的「前往文件夹」中检查 `~/Library/Application Support/com.hghub.huangguo/` 下的 `debug.log`（实际目录因系统与安装方式可能不同）。分享前检查日志是否含个人信息。

**重要：** 本仓库保留旧版客户端，原作者 [Minireel/HGhub](https://github.com/Minireel/HGhub) 现已转向插件式播放器。两套代码历史不兼容；**不要使用 Sync fork 强行覆盖本仓库的主分支。** 本应用「检查更新」仅查看本仓库的 Releases，不能将上游独立产品的版本当作本应用的升级包。

## 本地开发

基础环境：Node.js 22、pnpm 10、Rust 1.90 或更高版本，以及目标平台所需的 Tauri 开发环境。

```bash
pnpm install --frozen-lockfile
pnpm dev             # 前端开发
pnpm app:dev         # 桌面应用开发
pnpm build           # 类型检查与前端构建
```

各平台配置位于 `src-tauri/tauri*.conf.json`。移动端及 macOS 开发需要相应平台的 SDK 和工具链。

- exFAT 等不支持符号链接的文件系统需保留 `.npmrc` 中的 `node-linker=hoisted`；部分原生构建步骤仍可能受文件系统限制。
- 依赖安装脚本的允许列表见 `package.json` 与 `pnpm-workspace.yaml`。
- 内容处理、网络安全边界与本地回归说明见[客户端内容与网络安全](docs/security.md)。
